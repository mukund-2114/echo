# Contributing to Echo

Thank you for your interest in Echo! While this is primarily a personal project, feedback and suggestions are always welcome.

## 🎯 Project Status

Echo is currently a **personal portfolio project** being developed by Mukund. The primary goal is to create a functional AI companion app that demonstrates technical skills and product thinking.

## 💡 How You Can Help

### Feedback Welcome

- **Feature Suggestions:** Ideas for new features or improvements
- **Bug Reports:** Issues you encounter while using the app
- **UX Feedback:** Thoughts on user experience and design
- **Technical Advice:** Suggestions for better architecture or implementation

### Not Accepting

- **Pull Requests:** Not accepting code contributions at this time
- **Major Feature Additions:** Keeping scope focused for portfolio purposes

## 📝 Providing Feedback

### Bug Reports

If you find a bug, please include:

1. **Description:** What happened vs. what you expected
2. **Steps to Reproduce:** Detailed steps to recreate the issue
3. **Environment:** Device, OS version, app version
4. **Screenshots:** If applicable

**Example:**
```
**Bug:** App crashes when logging mood

**Steps:**
1. Open app
2. Tap mood selector
3. Select "Great" mood
4. App crashes

**Environment:**
- Device: iPhone 13
- iOS: 17.0
- App Version: 1.0.0

**Screenshot:** [attached]
```

### Feature Suggestions

When suggesting features, please include:

1. **Use Case:** Why this feature would be valuable
2. **Description:** What the feature should do
3. **Priority:** How important is this to you

**Example:**
```
**Feature:** Voice input for mood logging

**Use Case:** Sometimes I'm too tired to type, voice input would make logging faster

**Description:** Add a microphone button that converts speech to text for mood notes

**Priority:** Nice to have
```
